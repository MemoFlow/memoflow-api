# AI rework on OpenRouter

Moves the AI layer from Anthropic to OpenRouter and adds a versioned prompt system, retrieval over
the user's own content, per-user and global limits, guardrails, caching and AI data consent. One PR
per slice, each through the standard pipeline in `CLAUDE.md`. Task state lives in
`2026-11-06-ai-rework.md.tasks.json`.

This repository is public, so this file records the work, not vulnerability details.

## Decisions

- **Provider:** OpenRouter through a single gateway port, using native `fetch`. Models are env config.
- **Free models may process real users' data**, so disclosure and recorded consent ship first for
  real use. The notice needs legal review.
- **Retrieval:** Postgres full-text search, behind a port so vector search can replace it later.
- **Limits:** 10 requests per user per day and 40 in total per day, both env-configurable.
- **Access:** all active users within limits; tighten to verified emails after authz Phase 3.
- **AI quota and input limits move here** from authz Phase 4.

## Slices

0. **Pipeline reliability.** An unavailable broker can't block boot or hang publishing; gathered
   chunks can't be lost at finalization.
1. **Gateway.** `LlmGateway` port and OpenRouter adapter; remove the Anthropic SDK and env vars.
2. **Prompt system.** System templates, invocable feature types, renderer, versioned prompts shipped by
   migration, admin prompt endpoints, model recorded on results.
3. **Guardrails.** Input limits, secret redaction, untrusted-data delimiting, output validation,
   timeouts and retries, generic client errors.
4. **RAG.** Full-text index, `SectionRetriever`, shared `PlanningPipeline`, cited sources.
5. **Quota and caching.** Redis daily counters, per-user response cache, active prompt cache.
6. **Consent and notice.** Recorded AI consent, draft notice, frontend guide.
7. **Docs sweep.** Security runbook, privacy inventory, README, roadmap, live smoke on dev.

## Out of scope

Vector search, streaming, moderation API, usage dashboards, staging and production hosting.
